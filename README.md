# Luciano Fashion House

**Luciano Fashion House** është një webfaqe moderne dhe interaktive për një shtëpi mode, e ndërtuar me **React** dhe **Vite**.  
Ky projekt tregon koleksionet, brendet, dhe mundëson një përvojë reale për vizitorët që të eksplorojnë dhe të porosisin online.

---

## Teknologjitë e përdorura
- **React** – për komponentë interaktivë dhe SPA
- **Vite** – për build dhe Hot Module Replacement (HMR)
- **CSS / Google Fonts** – dizajn modern dhe responsive
